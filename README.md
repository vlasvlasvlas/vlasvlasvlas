## Trabajo

Actualmente soy **Product Owner & Data / AI Engineer en el Banco Interamericano de Desarrollo**, donde trabajo en productos de transparencia pública, sistemas LLM, ingeniería de datos y plataformas de inversión pública para América Latina y el Caribe.

- **MapaBot** — producto GenAI/RAG para conversar con datos de inversión pública.
- **MapaInversiones** — arquitectura, datos y evolución de plataformas abiertas de transparencia ([aplicación](https://github.com/EL-BID/MapaInversiones) · [datos](https://github.com/EL-BID/data-Mapainversiones)).
- **Data engineering** — pipelines ETL/EL, OCDS, Spark, Databricks, SQL y automatización cloud.

También trabajé con **CEPAL / Naciones Unidas**, gobiernos nacionales y locales, y comunidades de datos y geomática abierta. Fui parte de **Sistemas Mapache** y sigo cerca de OpenStreetMap, HOT, Geoinquietos y FOSS4G.

Entre esos cruces también están el portal CKAN de datos abiertos del Ministerio de Energía, trabajo humanitario con IFRC/HOT y [**Covid19arData**](https://github.com/SistemasMapache/Covid19arData), un dataset abierto reconocido con medalla de bronce en Kaggle.

`Python` · `SQL` · `PostgreSQL / pgvector` · `LLMs / RAG` · `Spark / Databricks` · `Airflow` · `FastAPI` · `Docker` · `Azure / GCP` · `PostGIS` · `Leaflet` · `Web Audio API`
